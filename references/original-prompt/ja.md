アップロードした写真をそれぞれ、独立した上質なデザインポスターにしてください。複数写真を連結せず、写真ごとに個別出力します。全体は3:4の縦位置構図とし、上下2領域の高さを厳密に1:1、画面の50%ずつにします。

上半分には元写真を残し、主体の同一性、構造、姿勢、現実の質感、自然な光と影、元の色彩の空気感を維持します。アート雑誌、インディペンデント出版物、ライフスタイルビジュアルの質感が出る程度に、繊細で上質な色調補正だけを施します。画面比率に合わせて周辺環境を自然に拡張しても構いませんが、主体を引き伸ばしたり、歪めたり、改変したりしてはいけません。

下半分では、写真の中で最も識別性の高い**主体同士の関係、物の特徴、暮らしの細部、物語の記憶点**を抽出し、「日本的な暮らしの断片 Scene Map／アクリル・コレクション図鑑」として再構成します。写真全体をそのまま複製してはいけません。元画像から、最も記憶に留める価値のある要素を約4〜7個、自由に選びます。人物の一部、食べ物、飲み物、器物、植物、動物、建築の特徴、乗り物、または感情的な価値を持つ小さなディテールなどが候補です。

各要素は**現実的で、明瞭で、触れられそうな物体の質感**を保ち、平面的な漫画表現にはしません。全体を、よりInstagram的なライフスタイル感のある色調に統一します。柔らかな自然光、清潔なハイライト、クリーミーな明部、わずかなソフトフォーカス、透明感のある影、心地よい寒暖関係を用い、硬すぎるコントラストを適度に抑えて色を明るくし、物が優しく、精緻で、清潔で、癒やされるように見えながらも、実際に撮影されたものらしさを残します。外周には透明で丸みのあるアクリル／樹脂の縁、わずかな厚み、繊細なハイライト、柔らかな接触影を加え、プラスチックの3D玩具ではなく、実在する小型コレクションのように見せます。

複数の物を、固定された四分割グリッド、等間隔の横一列、統一サイズで配置してはいけません。それぞれの要素が持つ**大きさ、方向、形、視覚的な重さ**に応じて、動的に組織します。斜めの流れ、S字ルート、環状の囲み、上下のずらし、階段状のリズム、中央からの放射、2グループのクラスター、画面端からの入り込み、非対称な浮遊など、異なる構図を採用できます。大きさの対比、わずかな回転、部分的な重なり、端への接触、裁ち落としを許容し、画像ごとに異なる視覚リズムを持たせます。常に明確な読みの経路と十分な余白を保ち、活発でも乱雑ではなく、リラックスしていても秩序のある状態にします。

要素間には、**細い点線、曲線の矢印、経路ノード、位置記号、ドット、括弧、手描きの小さな線、軽やかなマーク**を自由に加え、構図の流れに沿って自然につなげられます。すべての要素を必ず連結する必要はありません。線は迂回したり、飛び越したり、途切れたり、部分的なループを作ったりしてもよく、フローチャートや複雑なインフォグラフィックではなく、丁寧に整理された私的な memory map のような版面にします。

背景色には淡色の固定テンプレートをあらかじめ設定せず、上の写真の**主となる色相、全体の色温度、光、感情**に合わせて知的に選びます。クリーム、霧のようなブルー、セージグリーン、ピーチピンクだけでなく、レンガ色、キャラメルブラウン、ウォームオレンジ、グレイッシュブルー、深緑など、より重みのある複合色も使用できます。重要なのは、現実的な物体と美しい色彩対比をつくり、統一されたInstagram的な空気感を生むことです。全体の色は適度に明るく、澄ませ、柔らかく調整し、温かく、透明感があり、生活の気配を持たせます。濁った灰色、死んだ黒、蛍光色、高彩度の色衝突、安価なフィルターを避けます。

文字とルートを一緒に構図へ参加させます。各アイテムの属性、動き、感情、暮らしの連想をもとに、短く愛らしいラベル、単語、短文、記号を自由に生成します。固定語彙を設けず、言語も制限せず、すべてのアイテムに同一形式を強制しません。文字は、**軽やかで丸みがあり、自然な手書きの揺らぎと日本の手帳らしさを帯びた生活記録風書体**を使います。少量の細い小文字、付箋のような文字、微小な記号を組み合わせ、物と経路とともに柔軟な図文混植をつくります。
