업로드한 각 사진을 여러 사진 콜라주가 아닌 독립적인 고급 포스터로 만듭니다. 3:4 세로 캔버스를 위아래 50%씩 나눕니다.

위쪽에는 주체의 정체성, 구조, 자세, 질감, 자연광과 색 분위기를 보존한 원본 사진을 둡니다. 필요할 때 환경을 자연스럽게 확장하되 주체를 늘리거나 왜곡하지 않습니다.

아래쪽은 사진에서 기억에 남는 4~7개 요소(인물 일부, 음식, 음료, 물건, 식물, 동물, 건축, 교통수단, 정서적 디테일)를 골라 일본식 라이프스타일 ‘Scene Map / 아크릴 컬렉션 도감’으로 재구성합니다. 사진 전체를 복사하지 않습니다.

각 요소는 평면 만화가 아니라 현실적이고 선명하며 만질 수 있는 질감을 유지합니다. 부드러운 자연광, 깨끗한 하이라이트, 크리미한 밝은 부분, 반투명한 그림자와 편안한 색온도를 사용합니다. 둥근 투명 아크릴·레진 테두리, 미세한 두께, 섬세한 광택과 접촉 그림자를 더해 플라스틱 3D 장난감이 아닌 실제 소형 컬렉션처럼 보이게 합니다.

고정된 사분할 그리드, 같은 간격의 가로 배열, 동일한 크기를 사용하지 않습니다. 대각선 흐름, S자, 고리, 계단, 방사형, 두 그룹, 가장자리 진입, 비대칭 부유 등으로 동적으로 배치합니다. 크기, 회전, 겹침, 재단과 여백에 변화를 주되 하나의 읽기 경로를 유지합니다.

필요한 경우에만 가는 점선, 곡선 화살표, 노드, 위치 기호, 점, 괄호와 손그림 선을 더합니다. 선은 돌아가거나 끊기거나 건너뛰거나 부분적으로 순환할 수 있으며, 순서도나 복잡한 인포그래픽이 되지 않게 합니다.

배경은 고정된 연한 템플릿이 아니라 사진의 색상, 온도, 빛과 감정에 맞춥니다. 크림, 안개빛 파랑, 세이지, 복숭아, 벽돌, 캐러멜, 따뜻한 오렌지, 회청, 짙은 녹색 등을 사용할 수 있습니다. 탁한 회색, 죽은 검정, 형광 충돌과 값싼 필터는 피합니다.

짧은 라벨, 주석과 기호도 경로의 일부로 사용합니다. 일본 다이어리 같은 가볍고 둥근 손글씨와 필요한 경우 작은 가는 활자를 섞습니다. 현실적이고 따뜻하며 깨끗하고 생동감 있고 정교하게 완성하며, 고정 그리드, 평균 배치, 평면 만화, 복잡한 UI, 화살표 과다, 플라스틱 전자상거래 느낌과 템플릿 구성을 피합니다.
