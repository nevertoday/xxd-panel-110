حوّل كل صورة مرفوعة إلى ملصق مستقل راقٍ، وليس كولاجاً لصور متعددة. استخدم لوحة عمودية 3:4 مقسومة إلى منطقتين أفقيتين متساويتين بنسبة 50%.

حافظ في الأعلى على الصورة الأصلية وهوية الموضوع وبنيته ووضعه وملمسه وإضاءته الطبيعية وأجوائه اللونية. وسّع البيئة طبيعياً عند الحاجة، ولا تمدد الموضوع أو تشوّهه أو تغيّره.

في الأسفل، اختر 4–7 عناصر لا تُنسى من المصدر — تفاصيل شخص أو طعام أو شراب أو أدوات أو نباتات أو حيوانات أو عمارة أو وسيلة نقل أو شظايا ذات قيمة عاطفية — وأعد بناءها كـ Scene Map يابانية للحياة اليومية أو كتالوج مقتنيات أكريليك. لا تنسخ الصورة كاملة.

حافظ على واقعية كل عنصر ووضوحه وملمسه القابل للمس، لا على كرتونية مسطحة. استخدم ضوءاً طبيعياً ناعماً ولمعاناً نظيفاً وأجزاء مضيئة كريمية وظلالاً شفافة وحرارة لونية مريحة. أضف حواف أكريليك أو راتنج شفافة مستديرة وسماكة خفيفة ولمعاناً دقيقاً وظلال تماس، ليبدو كل عنصر مقتنى حقيقياً صغيراً لا لعبة بلاستيكية ثلاثية الأبعاد.

لا تستخدم شبكة رباعية ثابتة أو صفاً متساوي المسافات أو أحجاماً موحّدة. نظّم العناصر عبر تدفق قطري أو مسار S أو حلقة أو درجات أو إشعاع مركزي أو مجموعتين أو دخول من الحافة أو عوم غير متناظر. غيّر المقياس والدوران والتداخل والقص والفراغ مع الحفاظ على مسار قراءة واحد.

أضف فقط علامات المسار المفيدة: خطوطاً منقطة رفيعة أو أسهماً منحنية أو عقداً أو رموز موقع أو نقاطاً أو أقواساً أو خطوطاً مرسومة يدوياً. يمكن أن تلتف أو تنقطع أو تقفز، لكن النتيجة خريطة ذاكرة شخصية لا مخطط تدفق أو إنفوغرافيك كثيف.

طابق الخلفية مع درجة لون الصورة وحرارتها وضوئها ومشاعرها، لا مع قالب فاتح ثابت. يمكن استخدام الكريمي والأزرق الضبابي والمريمي والخوخي والطوبي والكراميل والبرتقالي الدافئ والرمادي المزرق والأخضر العميق. أضئ الألوان ونعّمها وتجنب الرمادي المتّسخ والأسود الميت والتصادم الفلوري والفلاتر الرخيصة.

اجعل الملصقات القصيرة والملاحظات والرموز جزءاً من المسار، بخط يد خفيف مستدير يشبه دفتر اليوميات الياباني مع حروف دقيقة صغيرة عند الحاجة. حافظ على الواقعية والدفء والنظافة والحيوية والرقي، وتجنب الشبكات الثابتة والتوزيع المتساوي والكرتون المسطح وواجهات UI المعقدة وكثرة الأسهم والبلاستيك الرخيص وتخطيط القوالب.
